*   Desarrolló una aplicación full stack de gestión de publicaciones y comentarios como prueba de laboratorio técnica, superando exitosamente la evaluación para una vacante de Consultor Fullstack en Albatros Services.
*   Arquitectó una API REST basada en microservicios con NestJS 10 y Mongoose, consumida por un cliente SPA construido en Angular 18+ con Signals y RxJS.
*   Implementó autenticación JWT, formularios reactivos, paginación real, pipes y directivas personalizadas, e internacionalización en tiempo de ejecución (es-MX / en-US).
*   Orquestó el despliegue local mediante Docker y Docker Compose, conectando los servicios a una base de datos MongoDB Atlas.
